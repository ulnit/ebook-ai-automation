# Chapter 5: Digital Products That Sell

## The GitHub-PayPal Stack

Why this works:
1. **GitHub** = Free hosting, built-in distribution, trust signal
2. **PayPal.me** = Zero integration, instant setup, global payments
3. **GitHub Pages** = Free landing pages, custom domain support

## Product Categories (Ranked by Profit)

### 1. AI Prompts ($3.99-9.99)
- Market: PromptBase (270,000+ prompts)
- Best: ChatGPT Skills ($9.99), Image Prompts ($3.99)
- AI can generate 20+ per batch
- Passive: upload once, earn forever

### 2. CLI Tools ($9-15)
- Market: GitHub + PyPI
- Example: web-fetch, json-query, file-watch
- Zero-dependency, stdlib-only
- Trust building: open source → paid support

### 3. Templates ($5-15)
- Notion templates: habit trackers, content calendars
- Excel/Google Sheets: budget trackers, analytics dashboards
- HTML/CSS: landing pages, portfolio sites

### 4. Ebooks/Guides ($9-29)
- Technical guides with code examples
- "Build X in Y minutes" format
- Include downloadable resources

### 5. Data Products ($9-49/month)
- Curated datasets
- Weekly trend reports
- Industry analysis
