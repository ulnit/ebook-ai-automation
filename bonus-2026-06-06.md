## One Agent Is Good. A Swarm Is Unstoppable.

A single AI agent can automate one task. But income streams don't come from one task — they come from coordinated workflows. The solution: run multiple specialized agents that talk to each other, each owning a piece of the pipeline.

And yes — this still runs on one $35 Raspberry Pi.

Each agent is a cron-triggered LLM call with a dedicated skill file. They pass data through a shared SQLite database — no message queues, no microservices, no Kubernetes.

## The Shared Database

```python
import sqlite3, json, time

DB = "/home/pi/swarm/tasks.db"

def init_db():
    conn = sqlite3.connect(DB)
    conn.execute("""
        CREATE TABLE IF NOT EXISTS tasks (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            agent TEXT NOT NULL,
            status TEXT DEFAULT 'pending',
            input_data TEXT,
            output_data TEXT,
            created_at REAL,
            completed_at REAL
        )
    """)
    conn.commit()
    return conn
```

Polls the DB for completed research tasks. For each one, calls the LLM to draft a blog post or social thread.

```python
        )
        conn.execute("UPDATE tasks SET status='processed' WHERE id=?", (row_id,))
    conn.commit()
```

## Agent 3: The Publisher

Takes completed content and pushes it to Dev.to, Medium, or a GitHub Pages blog. Updates the DB with live URLs for the monetizer.

## Why This Works

- **Parallelism on one device** — Each agent is a cron entry, not a long-running process. The Pi handles 10+ agents easily.
- **Decoupled failures** — If the publisher breaks, researcher keeps working. No cascading failures.
- **Self-healing** — A watchdog agent queries `tasks WHERE status='pending' AND created_at < now - 3600` and retries stale jobs.
