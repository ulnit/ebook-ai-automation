## Useful Python Libraries

All stdlib — no pip install needed:
- `urllib.request` — HTTP client
- `json` — JSON parsing
- `gzip` — Decompression
- `datetime` — Date handling
- `hashlib` — Checksums
- `sqlite3` — Local database
- `csv` — CSV processing
